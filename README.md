# 3D Map Viewer with Google My Maps Integration

FBX 3DモデルとGoogle My Mapデータを統合した、インタラクティブな3Dマップビューアーです。

## 機能

- **FBX 3Dモデルの表示**: Three.jsを使用した高品質な3D表示
- **Google My Mapデータの読み込み**: KMZ/KMLファイルからポイント情報を抽出
- **2つの表示モード**:
  - 鳥瞰モード: 全体を俯瞰してマーカーと情報カードを表示
  - ウォークスルーモード: 一人称視点で移動し、近くのポイント情報を表示
- **座標変換システム**: 緯度経度からローカル3D座標への変換
- **インタラクティブなUI**: リアルタイムで座標調整可能

## セットアップ

```bash
npm install
npm run dev
```

ブラウザで http://localhost:5174/ にアクセス

## Google My MapのKMZファイルについて

### 重要: ネットワークリンク形式について

Google My MapからエクスポートされたKMZファイルは、実際のデータを直接含んでいません。代わりに、**ネットワークリンク**という形式で、データの場所（URL）を指し示すだけの構造になっています。

#### KMZファイルの構造

```
my-map.kmz
└── doc.kml  ← ネットワークリンクのみを含む
    └── <NetworkLink>
        └── <href>https://www.google.com/maps/d/kml?mid=xxx&lid=xxx</href>
```

実際のポイントデータは、このURLにアクセスして取得する必要があります。

### 使用方法

#### 方法1: 自動取得（推奨）

1. Google My Mapで「KMLにエクスポート」を選択
2. ダウンロードしたKMZファイルをアップロード
3. アプリが自動的にネットワークリンクを解析し、データをフェッチします

**注意**: CORSポリシーにより、一部のブラウザやネットワーク環境ではフェッチに失敗する場合があります。

#### 方法2: 手動でKMLを取得（CORS対策）

CORSエラーが発生した場合の代替手段：

1. ダウンロードしたKMZファイルを解凍（.zipとして扱える）
2. `doc.kml`をテキストエディタで開く
3. `<href>`タグ内のURLをコピー
   ```xml
   <href>https://www.google.com/maps/d/kml?mid=xxx&lid=xxx</href>
   ```
4. そのURLをブラウザで開き、表示されるKMLファイルを保存
5. 保存したKMLファイルをアップロード

#### 方法3: Google Takeoutを使用

1. [Google Takeout](https://takeout.google.com/)にアクセス
2. 「マイマップ」を選択してエクスポート
3. ダウンロードしたファイルから実際のKMLを取得

## 使い方

### 1. KMZ/KMLファイルのアップロード

左上の「KMZ/KMLファイルを開く」ボタンをクリックして、ファイルを選択します。

成功すると、読み込まれたポイントの数が表示されます。

### 2. 座標設定の調整

「座標設定を開く」ボタンをクリックして、基準点パネルを表示します。

#### 基準点設定のパラメータ

- **緯度・経度**: 3D空間の原点に対応する地理座標
- **X座標・Z座標**: 基準点の3D空間での位置
- **スケール**: 地理座標とローカル座標のスケール係数（小さいほど縮小）
- **回転**: 北方向の調整（度単位）

#### 調整のコツ

1. 最初にKMZファイルを読み込むと、自動的に中心点が設定されます
2. スケールスライダーを調整して、ポイントが3Dモデル上に適切に配置されるようにします
3. 回転スライダーで方位を合わせます
4. 必要に応じて緯度経度やXZ座標を微調整します

### 3. 表示モードの切り替え

#### 鳥瞰モード

- 全体を俯瞰して確認したい場合に使用
- 各ポイントにマーカーと情報カードが表示されます
- 操作:
  - 左クリック + ドラッグ: 回転
  - 右クリック + ドラッグ: 移動
  - スクロール: 拡大/縮小

#### ウォークスルーモード

- 一人称視点で3D空間を歩き回る
- 近くのポイント（半径20m以内）の情報のみ表示
- 操作:
  - 画面をクリックしてポインターロックを有効化
  - WASD: 移動
  - マウス: 視点変更
  - ESC: ポインターロック解除

## トラブルシューティング

### KMZファイルが読み込めない

**症状**: 「ネットワークリンクからデータを取得できませんでした」というエラー

**原因**: CORSポリシーによりGoogleのサーバーからKMLをフェッチできない

**解決策**:
- 方法2（手動でKMLを取得）を試してください
- または、ブラウザのCORS拡張機能を使用（開発環境のみ）

### ポイントが3Dモデル上に正しく配置されない

**原因**: 座標変換の設定が適切でない

**解決策**:
1. 「座標設定を開く」から基準点を調整
2. スケールを小さくする（0.001〜0.1程度）
3. 回転角度を調整
4. 緯度経度が正しいか確認

### 画像が表示されない

**原因**: Google My Mapの画像URLがCORSで保護されている

**解決策**: 現時点では画像の直接表示は制限される場合があります
